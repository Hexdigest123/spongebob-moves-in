# SpongeBob Moves In! Reimagined

A fan-made recreation of the original SpongeBob Moves In! city-building game released in 2013.

Build Bikini Bottom, unlock iconic characters, complete quests, and bring the underwater world back to life.

*Built with C and Raylib.*


## What is SpongeBob Moves In! Reimagined?

SpongeBob Moves In! Reimagined is an open-source recreation of the original SpongeBob Moves In! mobile game.

The goal is to recreate the charm, progression, humor, and city-building gameplay that made the original game so memorable while making it available on modern platforms.

Whether you played the original game for years or are discovering it for the first time, this project aims to bring the experience back to life.


## Features

### Build Your Own Bikini Bottom

Create and expand your own version of Bikini Bottom with houses, businesses, landmarks, decorations, and more.

### Meet Iconic Characters

Unlock and interact with familiar faces from the SpongeBob universe as your town grows.

### Complete Quests

Progress through storylines, objectives, and character-driven quests inspired by the original game.

### Multiplayer

Visit other players' Bikini Bottoms and sync your game progression to play on other devices.

### Shop

The in-game shop that existed before the shutdown will be removed entirely from the local offline experience.

Meanwhile, in the online experience, you will be able to use the shop, but instead of benefiting this project, we will introduce a system that allows you to donate money to registered charitable organizations and receive your in-game purchases through that.
Since this feature requires a significant amount of time, it will be implemented once the game's core has been rebuilt and time allows for it.

### Cross-Platform

Planned support for:

* Windows
* Linux
* macOS
